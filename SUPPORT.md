# Support

TACResQ is an educational and engineering project, not an emergency-services provider.

For a real emergency, contact your local emergency services directly. Do not rely on this repository, its demo backend, its dashboard, or its GPS workflows for urgent assistance.

For project questions:

- Read the root [`README.md`](README.md).
- Check the setup and backend documentation in [`docs/`](docs/).
- Search existing GitHub issues.
- Open a new issue only when it contains no private, personal, credential, or real emergency information.

For suspected security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.
