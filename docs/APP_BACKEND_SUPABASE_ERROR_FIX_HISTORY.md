# TACResQ app, backend, and Supabase error-fix history

**Evidence boundary.** This report consolidates the supplied read-only audit results and the existing requester issue report. It is not an exhaustive history of every repository change, a live-system health report, or proof that merged code is deployed. Status below is only as strong as the cited repository, PR, CI, or dated audit evidence. No source files, databases, Render services, Supabase projects, deployments, or user data were changed for this report.

## Executive summary

The evidence spans requester SOS/edit/cancel/chat/notifications, Android auth/session/maps/offline behavior, Supabase schema/RPC/security, notifications/Realtime/FCM, and the repository’s Laravel/PHP bridge and dashboard. The requester stated that the app connects to a Render-hosted FastAPI server and Supabase. **This repository audit found a Laravel/PHP bridge and no FastAPI implementation; whether the deployed FastAPI service is separate, in another repository, or alongside the Laravel bridge remains unresolved.** Therefore this report covers repository-visible Laravel/PHP integration and the recorded Supabase evidence, not a verified inventory of the user's deployed FastAPI service. Several important code fixes are merged, but the requester cancellation and incident-chat migrations were recorded as **not applied** to the connected Supabase project as of 2026-11-10. The notification inbox/realtime audit documents some migrations as applied, but that status was not independently re-queried in these audits. There is **no separate staging project** documented. Render deployment identity and current live service state were generally not verified.

The requester’s original timeline is retained in §2 and linked to the integrated issue ledger; it is not repeated as a second standalone history. Confidence labels refer to confidence in the code/schema diagnosis, not proof of user impact: **High/confirmed** means directly supported by source, a corrective change/test, or the dated read-only live inspection; **Moderate** means a well-supported implementation explanation but no reproduction; **Unconfirmed** means the symptom’s cause is unknown.
