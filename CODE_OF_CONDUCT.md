# Code of Conduct

## Our standard

TACResQ contributors are expected to be respectful, constructive, and mindful that this project discusses emergency-response workflows and location data.

We welcome collaboration across experience levels. Harassment, discrimination, intimidation, personal attacks, doxxing, sexualized conduct, and publishing private or sensitive information are not acceptable.

## Expected behavior

- Give and receive actionable feedback respectfully.
- Focus criticism on the work, not the person.
- Protect personal, location, account, and emergency information.
- Prefer evidence, reproducible steps, and clear documentation.
- Respect project maintainers and community moderation decisions.

## Enforcement

Report unacceptable behavior privately to the repository maintainers. Maintainers may edit or remove content, close discussions, restrict participation, or take other action they consider appropriate to keep the project safe and constructive.
